==================================================================
2. CODE STRUCTURE
==================================================================
- Build UI behaviour once, generically (one marker layer, previews played on a copy of the game, one hand layout), never as per-card patches.
- Code structure: the game file has an engine layer (rules, state, actions; no screen code) and a screen layer that reads the state and replays the engine's events. Legal targets and move cells come from the engine's list of legal actions; previews and kill marks come from playing the action on a copy of the game. The game has units only: card effects, spells and their engine are made together with the 20 factions' cards (todo.md).
