## How to talk to Kaptain
- Short sentences. Plain everyday words. Say what happened and what you need, nothing else.
- Talk no more than necessary: the fewest lines the answer needs. No explanations, options or background Kaptain didn't ask for.
- Never use words Kaptain hasn't used or agreed to (no "happening", "payoff", "generic layer", "flat_ref", etc.); explain with a card example instead.
- One question at a time, answerable with yes/no or a choice. Put it last, alone, clearly marked as the question.
- No recaps, no lists of everything done, no caveats unless they change what Kaptain must decide.
- When a mistake is found, fix its cause in the docs (this file or the entry file the task uses) in the same turn, then say in one line what changed; never only admit it.
- When Kaptain says he doesn't understand or doesn't know something, explain it plainly and wait. Do not act until he answers.
- When a message asks for suggestions or shares a plan, even next to a task ("make X, and look at my plan"), agree the whole plan in conversation first. No code, no measurements, until he says go.

## Finding things (before reading anything)
- `python3 tools/find.py kw <Keyword>` — the cards with it and every code line using its flag (fix-all-cards checks start here).
- `python3 tools/find.py card <name>` — the card's data line and its summary lines.
- `python3 tools/find.py where <identifier>` — definition and uses in the game code.
- `python3 tools/find.py doc <text>` — matching lines in summary/ and factions/.
- `python3 tools/network_check.py factions/designs/<faction>.txt` — the network check of a faction design (mechanics, cards, decks: setups per cash-in, cards in two mechanics, needs with no maker, twins). Format in the tool's header. For the seven factions of 4 Nov 2026 give both files (`<faction>.txt <faction>-cards.txt`); the cards file is made from the game by `node tools/design_cards.js <letter>`.
- `node tools/cardstats.js <letter>` — Benchmark games with the faction's decks; per card: games, plays, effects fired, win rate.
- `node tools/net_byname_check.js` — a saved network still loads, by name, after the printed values or the rules' keyword list change.
- `node tools/ifelse_speed.js [depth] [positions] [where] [lab]` — the ifelse AI (Benchmark search) on fixed positions: time per move and a hash of its decisions; a speed change must keep the hash ("where": where the time goes; "lab": the lab's starting values with every keyword value 1). Also lists keywords on unit cards with no line in `js/ai/keyword-worth.js`.
- `node tools/fxtest.js` — behaviour checks of the seven factions' keywords (checks in `tools/fxtest-checks.js`).
- `python3 tools/design_gate.py <letter>` — the design gate: a faction is finished only when it prints PASS (checks in its header: 100 cards, library file, sources, budget, twins by effect, round-end damage, spell share per cost, champions, hovers, network, play). The pre-commit hook `tools/hooks/pre-commit` runs it on every faction whose cards changed in play (cost, stats, keywords, effects; text, hover links, art and champion marks don't count: `tools/hooks/gameplay_changed.js`); never commit with `--no-verify`.
- `node tools/playtest.js [letters]` — card checks (every text renders live, deck order cost then name, 5 champions shown per faction, every keyword word has its hover), then real games (each faction's two premades against each other) and every scenario in headless Chrome; fails on any script error (about 5 minutes per faction with the scenarios).
- `python3 tools/set_benchmark.py "<file>.json"` — writes a Benchmark file from the AI lab's "Make this the Benchmark" into `js/ai/benchmark.js` (then build, simtest, summary/15).
- `node tools/summary_faction.js all` — writes `summary/11-faction-<name>.txt` from the game's cards (use when saving the summary).
- Otherwise `grep -n` in the one file the map names. Then read only the lines needed (`sed -n 'a,bp'` or Read with offset/limit, usually under 80 lines). Never read a whole part, doc or HTML file; never grep the built HTML.

## Workflow
